# Orval Generated React Query Client

The backend contract is generated by Orval from `NEXT_PUBLIC_OPENAPI_URL`.

## Files

- `orval.config.ts` configures generation.
- `src/api/generated/react-query/*` contains generated request functions, query options, hooks, and invalidation helpers.
- `src/api/generated/model/*` contains generated DTO and enum types.
- `src/api/mutator/custom-instance.ts` is the shared request layer for browser and server calls.
- `src/components/query-provider.tsx` installs TanStack Query defaults for generated hooks.

Do not edit files under `src/api/generated`. Update the OpenAPI schema or Orval config, then run:

```powershell
pnpm orval
```

`pnpm build` also runs Orval first. The env vars from `.env.example` must be present.

## Generated Module Shape

Each tag file exports a predictable set of tools:

- Direct async request function: `productsControllerAll(params, requestOptions, signal)`
- Query key helper: `getProductsControllerAllQueryKey(params)`
- Query options helper: `getProductsControllerAllQueryOptions(params, options)`
- React Query hook: `useProductsControllerAll(params, options, queryClient)`
- Infinite query variants when the endpoint is paginated.
- Mutation hook and mutation options for writes.
- Invalidation helper: `invalidateProductsControllerAll(queryClient, params)`
- Result, body, and error types.

## Client Components

Use generated hooks only in Client Components:

```tsx
"use client"

import { useProductsControllerAll } from "@/api/generated/react-query/products"
import { QueryErrorBoundary } from "@/components/query-error-boundary"

function ProductsTable() {
  const products = useProductsControllerAll(
    { page: 1, limit: 20 },
    {
      query: {
        staleTime: 60_000,
      },
      request: {
        auth: false,
      },
    }
  )

  if (products.isPending) {
    return <ProductsSkeleton />
  }

  if (products.isError) {
    return <ProductsInlineError error={products.error} />
  }

  return <ProductsRows products={products.data.data.products} />
}

export function ProductsPanel() {
  return (
    <QueryErrorBoundary>
      <ProductsTable />
    </QueryErrorBoundary>
  )
}
```

The first argument is endpoint params or body depending on the generated function. The `query` or `mutation` option goes to TanStack Query. The `request` option goes to `customInstance`.

## Mutations

Generated mutation hooks accept `{ data }` when calling `mutate` or `mutateAsync`:

```tsx
"use client"

import { useQueryClient } from "@tanstack/react-query"
import {
  invalidateProductsControllerAll,
  useProductsControllerAdd,
} from "@/api/generated/react-query/products"

export function AddProductForm() {
  const queryClient = useQueryClient()
  const addProduct = useProductsControllerAdd({
    mutation: {
      async onSuccess() {
        await invalidateProductsControllerAll(queryClient)
      },
    },
  })

  return (
    <form
      onSubmit={(event) => {
        event.preventDefault()
        addProduct.mutate({ data: buildAddProductDto(event.currentTarget) })
      }}
    />
  )
}
```

Keep validation and auth failures local to the form. Let unexpected failures bubble only when leaving the form is the better user experience.

## Server Components And Server Helpers

Do not call generated React hooks on the server. Use the direct async request functions.

Put server-only API helpers in route `_utils` files and add `import "server-only"`:

```tsx
import "server-only"

import { productsControllerAll } from "@/api/generated/react-query/products"

export async function getPublicProducts() {
  return productsControllerAll(
    { page: 1, limit: 20 },
    {
      auth: false,
      cache: "force-cache",
      next: {
        revalidate: 300,
        tags: ["products"],
      },
    }
  )
}
```

Use `auth: false` for public requests. Authenticated requests read cookies and default to `cache: "no-store"`, so do not put them in shared cache functions.

```tsx
import "server-only"

import { usersControllerCurrent } from "@/api/generated/react-query/users"

export async function getCurrentUser() {
  return usersControllerCurrent({
    cache: "no-store",
  })
}
```

## Cache Components

With `cacheComponents: true`, cache only public, deterministic generated calls:

```tsx
import "server-only"

import { cacheLife, cacheTag } from "next/cache"
import { productsControllerAll } from "@/api/generated/react-query/products"

export async function getCachedProductList() {
  "use cache"

  cacheLife("minutes")
  cacheTag("products")

  return productsControllerAll(
    { page: 1, limit: 20 },
    {
      auth: false,
      cache: "force-cache",
      next: {
        tags: ["products"],
      },
    }
  )
}
```

Never read `cookies()`, `headers()`, or request-specific auth state inside a `"use cache"` function. Read request-time values outside the cached function and pass only safe, serializable inputs.

## Server Error Handling

Generated request functions throw `ApiRequestError`. Convert expected states to Next routing primitives near the route:

```tsx
import { notFound, unstable_rethrow } from "next/navigation"
import { productsControllerById } from "@/api/generated/react-query/products"
import { isApiRequestError } from "@/api/mutator/custom-instance"

export async function getProductOrNotFound(id: string) {
  try {
    return await productsControllerById(id, { auth: false })
  } catch (error) {
    unstable_rethrow(error)

    if (isApiRequestError(error) && error.status === 404) {
      notFound()
    }

    throw error
  }
}
```

If the generated module does not export the endpoint name you expect, search the tag file. Orval names functions from the OpenAPI `operationId`.

## Hydrating Client Queries From The Server

Use hydration only when the client must continue owning the query after the first render:

```tsx
import { dehydrate, HydrationBoundary, QueryClient } from "@tanstack/react-query"
import { getProductsControllerAllQueryOptions } from "@/api/generated/react-query/products"
import { ProductsPanel } from "./_components/products-panel"

export default async function ProductsPage() {
  const queryClient = new QueryClient()

  await queryClient.prefetchQuery(
    getProductsControllerAllQueryOptions(
      { page: 1, limit: 20 },
      { request: { auth: false } }
    )
  )

  return (
    <HydrationBoundary state={dehydrate(queryClient)}>
      <ProductsPanel />
    </HydrationBoundary>
  )
}
```

For purely server-rendered content, prefer calling the direct generated function and passing plain serializable data into the UI.
